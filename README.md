# Имитационное моделирование СМО — Вариант №9

Курсовая работа по дисциплине «Имитационное моделирование вычислительной системы».

**Бизнес-домен:** Вычислительный центр ПВО.

---

## Вариант

`ИБ ИЗ1 ПЗ2 Д10З2 Д10О5 Д2П1 Д2Б5 ОР1 ОД3`

| Код | Расшифровка |
|---|---|
| ИБ | Бесконечные источники |
| ИЗ1 | Пуассоновский поток заявок |
| ПЗ2 | Равномерное обслуживание |
| Д10З2 | Постановка в буфер в порядке поступления (FIFO) |
| Д10О5 | При переполнении буфера отказ новой заявке |
| Д2П1 | Выбор первого свободного прибора по номеру |
| Д2Б5 | Приоритет источника, пакетная обработка |
| ОР1 | Автоматический режим (сводная таблица) |
| ОД3 | Пошаговый режим (временные диаграммы) |

---

## 1. Элементы бизнес-домена

### 1.1. Источник (ИБ, ИЗ1)

Сектора наблюдения, из которых в систему поступают заявки (цели). Поток заявок бесконечный (ИБ) и подчиняется пуассоновскому закону распределения (ИЗ1).

### 1.2. Буфер (Д10З2)

Зона сопровождения, в которой ожидают цели, не принятые на обслуживание немедленно. Новая заявка помещается в конец очереди — в порядке поступления (FIFO).

### 1.3. Прибор (ПЗ2)

Вычислительный модуль (условная ЭВМ), обрабатывающий заявки. Время обслуживания одной заявки распределено равномерно (ПЗ2).

### 1.4. Дисциплина отказа (Д10О5)

При переполнении буфера вновь поступившая заявка получает отказ и покидает систему необслуженной.

### 1.5. Дисциплины постановки на обслуживание (Д2П1, Д2Б5)

- **Д2П1** (выбор прибора по номеру) — диспетчер выбирает первый по порядку свободный прибор;
- **Д2Б5** (выбор заявок пакетами по источнику) — диспетчер обслуживает заявки приоритетного источника подряд, пока в буфере остаются его заявки, затем переходит к следующему по приоритету источнику.

### 1.6. Заявка

Обнаруженная цель, поступившая от источника и ожидающая либо получающая обработку на приборе.

---

## 2. Маппинг сущностей

| Сущность | Описание |
|---|---|
| Источник | Сектор наблюдения, из которого в систему поступает поток заявок (целей) |
| Заявка | Обнаруженная цель, поступившая от источника и ожидающая либо получающая обработку |
| Буфер | Зона сопровождения целей — общая очередь ожидания ограниченной ёмкости для заявок, не принятых на обслуживание немедленно. Постановка — в порядке поступления (FIFO, Д10З2). При переполнении отказ получает вновь пришедшая заявка (Д10О5) |
| Прибор | Условная ЭВМ, обрабатывающая одну цель за раз |
| Диспетчер постановки | Программный алгоритм. Направляет новую заявку на первый свободный прибор (Д2П1), в буфер (Д10З2) или отказывает новой заявке при переполнении (Д10О5) |
| Диспетчер выбора | Программный алгоритм. Берёт заявку из активного пакета или формирует новый пакет по приоритету источника (Д2Б5) |
| Пакет | Группа целей одного сектора, обслуживаемых подряд по правилу приоритета |
